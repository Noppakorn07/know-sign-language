# แนวทางเทรน AI ตรวจจับภาษามือไทย

เอกสารนี้เป็นแนวทางสำหรับต่อยอดจาก Prototype ไปเป็นระบบ AI จริง โดยเริ่มจากง่ายที่สุดก่อน

---

## เป้าหมาย AI ของโครงงาน

ให้ระบบสามารถดูภาพจากกล้อง แล้วทำนายว่าผู้ใช้กำลังทำภาษามือคำใด เช่น

- สวัสดี
- ขอบคุณ
- ขอโทษ
- กินข้าว
- ช่วยด้วย

ช่วงแรกไม่ควรเริ่มเยอะ ให้เริ่มแค่ 5-10 ท่าก่อน

---

## แนวทางที่ 1: ใช้ Teachable Machine ง่ายสุด

เหมาะสำหรับนักเรียนที่ยังไม่ถนัด AI มาก

### ขั้นตอน

1. เข้าเว็บ Teachable Machine ของ Google
2. เลือก Image Project
3. สร้าง Class เช่น
   - hello
   - thankyou
   - sorry
   - eat
   - help
4. เปิดกล้องแล้วอัดตัวอย่างแต่ละท่า
5. กด Train Model
6. Export เป็น TensorFlow.js
7. เอาโมเดลมาใส่ในเว็บ

### ข้อดี

- ง่ายมาก
- ไม่ต้องเขียน Python
- เหมาะสำหรับ Demo NSC

### ข้อเสีย

- อาจแม่นยำน้อยถ้าแสงหรือมุมกล้องเปลี่ยน
- ต้องเก็บตัวอย่างให้หลากหลาย

## แนวทางที่ 2: ใช้ MediaPipe Hands + Machine Learning

แนวนี้เหมาะกว่าในระยะยาว เพราะระบบจะดูตำแหน่งนิ้วแทนภาพทั้งหมด

### หลักการ

MediaPipe Hands จะตรวจจับจุดสำคัญของมือ 21 จุดต่อมือ เช่น

- ข้อมือ
- ข้อนิ้ว
- ปลายนิ้ว

จากนั้นนำพิกัด x, y, z ของจุดเหล่านี้ไปใช้เทรนโมเดล

### Pipeline

```txt
กล้องเว็บแคม
   ↓
MediaPipe Hands ตรวจจับมือ
   ↓
ได้ hand landmarks 21 จุด
   ↓
บันทึกเป็น dataset
   ↓
Train model
   ↓
นำ model ไปใช้ทำนายในเว็บ
```

---

## การเก็บ Dataset

เริ่มจาก 5 ท่าก่อน เช่น

```txt
hello
thankyou
sorry
eat
help
```

แต่ละท่าควรเก็บอย่างน้อย

- 100-300 ตัวอย่างต่อ 1 ท่า
- หลายมุมกล้อง
- หลายสภาพแสง
- หลายคน ถ้าทำได้

ถ้าทำคนเดียว ให้เปลี่ยนระยะใกล้/ไกล มุมซ้าย/ขวา แสงสว่าง/มืด เพื่อให้ข้อมูลหลากหลายขึ้น

---

## รูปแบบข้อมูลที่ควรเก็บ

ตัวอย่างไฟล์ CSV

```csv
label,x1,y1,z1,x2,y2,z2,...,x21,y21,z21
hello,0.41,0.52,-0.01,0.43,0.49,-0.02,...
thankyou,0.33,0.60,-0.02,0.35,0.57,-0.03,...
```

ถ้าใช้มือเดียวจะมี 21 จุด จุดละ 3 ค่า = 63 features

ถ้าใช้สองมือจะมี 42 จุด จุดละ 3 ค่า = 126 features

---

## โมเดลที่ใช้ได้

สำหรับเริ่มต้น ใช้โมเดลง่าย ๆ ก่อน เช่น

1. K-Nearest Neighbors หรือ KNN
2. Random Forest
3. Neural Network ขนาดเล็ก
4. TensorFlow.js model

ถ้ายังใหม่มาก แนะนำเริ่มจาก Teachable Machine ก่อน แล้วค่อยเปลี่ยนเป็น MediaPipe ภายหลัง

---

## วิธีแบ่งงานสำหรับ NSC

### Phase 1: Prototype

- ทำเว็บเรียนภาษามือ
- ทำ Quiz
- เปิดกล้องได้
- Mock ผลตรวจจับ

### Phase 2: AI ง่าย

- ใช้ Teachable Machine
- ตรวจจับ 5 ท่า
- แสดงผลบนเว็บ

### Phase 3: AI จริงจัง

- ใช้ MediaPipe Hands
- เก็บ landmarks
- Train model จาก dataset
- วัด accuracy

---

## วิธีวัดผล AI

ควรวัดอย่างน้อย

- Accuracy: ทายถูกกี่เปอร์เซ็นต์
- Confusion Matrix: ท่าไหนสับสนกับท่าไหน
- Response Time: ทำนายเร็วพอไหม

ตัวอย่างเป้าหมายแรก

```txt
ตรวจจับ 5 ท่า
Accuracy มากกว่า 80%
ทำงานบนเว็บแบบ real-time
```
